# Coolisimplify: cloning must carry custom network aliases

A worked example of the `prism-mock-testing` skill against this repo's Coolify
OpenAPI spec. The clone flow must send `custom_network_aliases` on the create
request; the mock proves it over the wire.

## Setup

```sh
# 1. Boot the mock (repo root)
prism mock coolify-openapi-v4.x.yaml --port 13000 --cors --multiprocess=false

# 2. Run a harness that drives the REAL CoolifyClient clone flow, asserting the wire body
```

## Harness

Use the skill's `scripts/prism-harness.mjs`. The Coolify client targets a
proxy prefix (`/api/coolify/...`) which the app's Next.js route forwards to
`{coolifyUrl}/api/v1/...`; the harness reproduces that proxy, injects the
Bearer token, and records the create body.

```js
import { harness } from '.agents/skills/prism-mock-testing/scripts/prism-harness.mjs'
import { CoolifyClient } from './apps/web/lib/coolify-client.ts'
import { cloneResource } from './apps/web/lib/clone.ts'

const h = harness({
  base: 'http://127.0.0.1:13000',
  // Coolify client goes through /api/coolify/... → strip the prefix and prepend
  // the mock base so the result is an absolute URL fetch can parse.
  rewriteUrl: (url) => `${base}${url.replace('/api/coolify', '')}`,
  auth: (headers) => headers.set('Authorization', 'Bearer abc'),
  watch: ['/applications/private-github-app'],
  transformBody: (body) => {
    // Prism's spec marks environment_name required; real Coolify treats
    // environment_uuid as an alternative. Inject it so Prism passes the body.
    if (!body.environment_name) body.environment_name = 'prod'
    return body
  },
})

const client = new CoolifyClient({ baseUrl: h.base, token: 'abc' })
await cloneResource(
  client, 'application',
  { id: 1, uuid: 'src-app', name: 'Source App', build_pack: 'nixpacks',
    source_id: 3, git_repository: 'org/repo', git_branch: 'main',
    ports_exposes: '3000', fqdn: 'https://a.example.com',
    custom_network_aliases: 'api,backend' },
  [],
  { projectUuid: 'proj', serverUuid: 'srv', environmentUuid: 'env',
    name: 'Source App-copy', domains: '', autogenerateDomain: false },
  {},
  [{ id: 3, uuid: 'gh-app-uuid', name: 'gh' }],
)

const last = h.route(h.seen, '/applications/private-github-app').at(-1)
if (last?.body?.custom_network_aliases !== 'api,backend') {
  throw new Error('clone did not carry custom_network_aliases')
}
h.restore()
```

## Notes

- **Red-capable:** delete the `custom_network_aliases` line from the source
  detail and the assertion fails (`undefined !== 'api,backend'`); with the
  field it passes. That is the red/green signal for the bug.
- **Spec overstates `required`:** Prism marks `environment_name` required, but
  Coolify's controller treats `environment_uuid` as an alternative — the
  `transformBody` seam exists for exactly this mismatch.
- **Prism doesn't 422 on unknown fields** (`--errors=false`): to catch
  unknown-field leaks, pair the mock with the repo's
  `scripts/check-clone-payload.mjs` (validates against the create schema plus
  the controller's `$allowedFields` allowlist).
